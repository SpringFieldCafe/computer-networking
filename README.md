# Computer Networking

本仓库公开计算机网络课程的理论推导、通用配置与辅助脚本。

| 实验 | 内容 | 入口 |
| --- | --- | --- |
| 实验二 | 交换机自学习、逐步转发表、eNSP 操作、抓包分析 | [实验二](exp2/README.md) |
| 实验三 | VLAN 划分、VLAN 间互通、eNSP 工程与证据采集工具 | [实验三](exp3/README.md) |

公开示例采用主机代号、文档用IP地址和模型MAC。脚本生成的模型数据带有模型标记，设备实测输出默认写入已忽略的本地目录。

所有图片、课程原件、个人报告、原始抓包、运行日志与个人操作记录保留在本地。作业材料中的照片也不纳入公开内容。
