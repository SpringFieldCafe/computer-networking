# Computer Networking

本仓库公开计算机网络课程的理论推导、配置、辅助脚本，以及经过审查的脱敏工程和仿真实测数据。

| 实验 | 内容 | 入口 |
| --- | --- | --- |
| 实验二 | 交换机自学习、eNSP 工程与助手、逐步转发表、脱敏日志及 UDP/MSTP 抓包 | [实验二](exp2/README.md) |

公开示例采用主机代号、文档用IP地址和模型MAC。脚本生成的模型数据带有模型标记，设备实测输出默认写入已忽略的本地目录。

实验二的公开实测副本见 [资料说明](exp2/evidence/README.md)。所有图片、课程原件、个人报告、原始抓包和原始日志继续保留在本地。

自编代码、说明和工程配置采用 [MIT 许可证](LICENSE)。eNSP、Wireshark、设备镜像和其他第三方程序由使用者自行安装。

`dev` 用于集成特性分支，验证通过的内容合并到 `main`。
